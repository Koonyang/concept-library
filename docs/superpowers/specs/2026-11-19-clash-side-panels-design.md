# 합 연출: 양쪽 책장 판 + 숫자 튀어 오름 + 찰나의 슬로우 (2026-11-19)

## 왜
지금 합은 화면 아래 가운데 판 한 장(`#clash-panel`)에 양쪽 책장·주사위를 표로 보여 준다. 읽을 수는 있지만 맞붙는 손맛이 없다.
큐 양이 원하는 것: 양쪽에 각자의 책장이 뜨고, 주사위 값이 크게 튀어 오르는 순간 0.2초 미만의 슬로우 모션과 함께 타격·피격 이펙트가 터지는 연출.

## 목표 / 하지 않을 것
- 목표: 책장 판 2장(사서 쪽·손님 쪽)이 **각 캐릭터 옆**에서 따라다닌다(큐 양 선택: B안, 비교 예시로 확인).
- 목표: 단계(주사위)마다 숫자 튀어 오름 → 슬로우 → 타격(밝게)·피격(붉게 + 흔들림).
- 하지 않음: 합 길이 규칙(1.0초, 단계당 +0.2초, 최대 1.6초) 바꾸기, 전투 규칙·엔진 바꾸기, 캐릭터 키우기.
- 실패로 보는 것: 판이 체력 막대·상태판·다른 주사위와 겹침, 숫자가 흔들려 못 읽음, 연출 때문에 합이 길어짐.

## 고른 방법 (Approaches)
| 안 | 내용 | 결과 |
|---|---|---|
| A 가장자리 고정 | 판을 화면 왼쪽·오른쪽 끝에 고정 | 읽기 쉽고 겹침 관리 쉬움. 캐릭터와 떨어져 보임 |
| **B 캐릭터 옆** | 판이 합 카메라로 모인 두 캐릭터 옆을 따라감 | **선택.** 맞붙는 느낌. 따라가기를 부드럽게 해서 흔들림을 줄임 |
| 가운데 판 개선 | 지금 판에 효과만 추가 | 요청과 반대(양쪽)라 뺌 |

## 설계
**판 (UI, `js/ui/battle.js`, `style.css`)**
- `#clash-panel` 안에 `.cp-side.l`(내 쪽, 늘 왼쪽) · `.cp-side.r`(상대 쪽) 판 2장. 판마다 유닛 이름, 책장 이름(큰 일격 표시), 주사위 줄(종류·범위·값 `?`·결과 글자, 재사용 표시).
- 대응 없는 쪽(일방 공격을 받는 쪽)은 "대응 없음" 판을 작게·흐리게.
- 위치: 매 프레임 `stage.unitPoint(id)`(머리 위 화면 좌표)를 기준으로
  - 가로: 내 판은 캐릭터 왼쪽(판 오른쪽 끝 = 머리 x − 여백), 상대 판은 캐릭터 오른쪽. 세로 위치는 머리 높이 근처.
  - 세로(폭 < 높이): 옆에 자리가 없으니 머리 위로 올리고, 왼쪽 반·오른쪽 반 안에서만 x를 따라간다(비교 예시와 같음).
  - 항상 화면 안, 체력 막대·상태판 아래(`barsFloor`), 두 판끼리 안 겹치게 밀어냄. 따라가기는 부드럽게(매 프레임 목표로 35%씩, 1px 이하는 안 움직임).
- 합이 연출되는 동안 속도 주사위 줄(`#dice-layer`)은 숨긴다(**내 결정**: 판이 같은 정보를 보여 주고, 캐릭터 옆 판과 머리 위 주사위가 겹치는 걸 막는다). 막이 끝나면 다시 보인다.
- 단계 i가 맞는 순간: 그 줄 숫자 공개 + 튀어 오름(1 → 1.8배 → 1.3배, 약 0.22초), 이긴 쪽 숫자 밝게, 진 쪽 흐리게 + 좌우로 흔들림. 이긴 판은 밝은 테두리 번쩍, 피해를 받은 판은 붉게 번쩍 + 흔들림. 판 아래 한 줄로 피해(체력 −N · 흐트러짐 −N / N 막음 / 회피).

**무대 (`js/stage/stage.js` `playDefault`)**
- 지금의 히트스톱(70ms 정지)을 **슬로우 모션으로 교체**: 맞는 순간 `time.scale = 0.25`를 실제 150ms 동안, 그다음 1로. SSR 감속(0.4배 300ms)은 그 뒤에 그대로.
- 빨리 감기(`fast`)면 슬로우 없음(지금처럼 짧은 정지만 또는 없음).
- 연출 길이는 벽시계 기준이라 슬로우가 합 전체 길이를 늘리지 않는다.
- 피해가 없는 단계(무승부·회피·전부 막음)에도 UI가 숫자를 낼 수 있게 `o.onStep(i)`을 단계마다 부른다(`onHit`은 지금처럼 피해 있을 때만). 전용 연출(`registerFx`) 경로도 같이 부른다.

**빨리 감기·건너뛰기**: 탭 = 슬로우·튀어 오름 없이 숫자만 바로. 길게 누르기 = 지금처럼 판 없이 건너뜀.
